# MangaFind V1 Benchmark

## Case 01·02·05 보완 기록

- Case 01: 한국어 후보에 출처 꼬리말이 남아 위키와 독립 커뮤니티의 같은 명칭이 별개로 집계되는 결함을 mock으로 재현했다. 출처 꼬리말만 정리하고 원제 연결·독립 출처 COMMON 조건·정발 분리를 유지한다. 당시 실제 운영 응답 전체는 없어 모든 실패 요청의 단일 원인이라고 단정하지 않는다.
- Case 02: OCR 한자 오류가 포함된 검색어가 공식 작품 결과의 관련성 필터와 후보 대조에서 탈락하는 경로를 mock으로 재현했다. 정규화·편집거리로 유사한 검증 전체 제목이 하나일 때만 교정하며 후보·클러스터·검색 근거의 연결을 함께 갱신한다. 보조 후보의 빈 근거로 전체 응답이 실패했던 기존 로그도 확인됐으며, 원제 미확인 UNKNOWN 보조 항목만 제외한다. 실제 작품의 근거 최소 개수는 낮추지 않는다.
- Case 02 실패 경로: 모델 판정이 실패해도 유일하게 검증된 교정 원제가 있으면 기존 fallback 제목으로 사용하고, OCR 오인식으로 되돌리지 않는다. 실패 상태·사유와 LOW 수준은 유지하며 검증 성공으로 위장하지 않는다.
- Case 01 상태 경계: 다른 공식명 후보가 존재하더라도 COMMON 이름에 정발 CONFIRMED를 전파하지 않는다. 통용명 사용 근거와 한국판 출판 근거를 분리한다.
- Case 05: 이전 로그와 현재 코드에서 LOW 이미지 신뢰도로 YES24가 호출되지 않는 조건이 확인됐다. 공식 한국판 검증 시 기존 최대 1회 조회를 복구한다. 해당 경로의 실제 요청 수는 0회에서 1회로 바뀔 수 있지만 상한은 늘지 않는다. 제공된 상품 URL과 나무위키 URL은 mock 회귀 데이터에만 사용한다. 표지 URL은 실제 응답이 없는 합성 fixture다.
- UI/응답: 링크 필드는 API 응답 스키마에 보존되며 나무위키와 YES24 카드는 서로 독립적으로 표시된다. Case 05의 표지 클릭 href와 출판사 표시는 서버 렌더 mock으로 검증한다. 실제 브라우저·외부 상품 페이지 접속 검증은 수행하지 않는다.
- 안전성: 모호한 공식 후보·미검증 출처·원서/직수입·충돌 원제/작가·ISBN 체크섬 오류·무관한 위키·리다이렉트 URL 오조합을 검증한다. ISBN이 없으면 다른 근거로 대조한다. 저자 표기의 언어 간 동등성은 일본 원제 등 추가 근거 없이 완전히 증명할 수 없다.
- 비용/개인정보: 이번 보완에서 실제 외부 API 호출은 0회다. 새 provider, 번역 호출, 페이지 수집, 재시도는 추가하지 않았다. 일반 출처 UI 확대와 OCR 원문 로그는 기존 V1 제약을 유지한다. 로그에는 원문 대신 단계별 요약과 제외 사유를 남긴다.

실제 API 비용을 보호하기 위해 자동화된 테스트는 mock gateway/provider만 사용하고 기본 fetch는 차단합니다. 실제 API benchmark는 비용 승인과 테스트 샘플 준비 후 수동으로 실행합니다.

## OCR 제목 복원 회귀 검증 (2026-10-25)

확인한 기존 경로:

- 로컬 OCR 정제는 괄호 제목만 추출하고, 나머지는 줄별 대사 최대 2개로 축소했다. 세 줄 전체 제목이 누락되는 현상을 제공 OCR fixture로 재현했다.
- OCR.space는 원문을 보존했지만, overlay 좌표는 crop 용도로만 사용하고 제목 후보 생성에는 전달하지 않았다.
- 전체 OCR의 일본어 비율이 낮으면 정제를 생략했다. SNS UI가 많은 이미지에서 실제 일본어 제목이 존재해도 이 경로에 들어갈 수 있었다.
- Tavily 관련성 검사는 짧은 일부 문자열 또는 trigram 일치만으로 결과를 인정했고, 관련 결과가 있으면 Lens를 생략했다.
- canonical resolver에는 전체 문자열 근거 검사가 이미 있었지만, 재구성 OCR 후보를 명시적으로 전달하지 않았고 검증 OCR 제목과 최종 선택의 일치를 보장하지 않았다. 한국 통용명 재판정에도 일본 원제 재대조가 빠져 있었다.

제공된 OCR 외에 당시 Tavily/Lens/Foundry 응답은 없으므로 특정 운영 요청이 어느 분기를 거쳤는지는 단정하지 않는다.

수정 후 기준:

- 원본 OCR을 fixture로 보존하며 제목은 최대 6줄·80자·6후보로 복원한다. 위치 정보가 있으면 수직 간격·높이·수평 겹침을 확인하고 이미지 경계를 넘지 않는다.
- SNS UI·계정명·반응 수는 기본 후보에서 제외하고, 일본어 캡션·해시태그·불확실한 대사 단서는 보존한다. 문자열만으로 제목을 확정하지 않는다.
- 전체 제목 일치 + 만화 문맥 + 알려진 일본 출판/연재 출처 또는 독립된 두 출처의 출판/연재 정보가 있어야 OCR 작품 검증이 성공한다. 같은 도메인의 하위 도메인을 독립 출처로 세지 않는다.
- 검증 후보가 하나이고 충돌이 없을 때만 Lens를 생략한다. 실패·부재·충돌 시 기존 단일 이미지 Lens를 사용한다. OCR 후보와 Lens 출처를 함께 비교하고 불확실하면 LOW 또는 INSUFFICIENT로 처리한다.
- 모델의 무관한 유명 작품·부분 제목 선택을 거부한다. 한국 검증·통용명 재판정이 일본 원제를 바꾸지 못하게 한다.

### 요청 예산 비교

아래는 캐시 미적중 기준이다. 새 provider 호출이나 재시도는 추가하지 않았다.

| API | 수정 전 구현 | 수정 후 구현 |
| --- | --- | --- |
| OCR.space | 이미지당 1회, 최대 3회 | 동일 |
| Lens | 선택 이미지 1장, 조건부 검색 기본 1회 | 동일, 조건만 작품 검증 기준으로 강화 |
| Lens upload/timeout retry | upload 1회, 검색 timeout 시 기존 최대 2시도 | 동일, Exact Matches·추가 이미지 없음 |
| Tavily 일본 검색 | OCR 최대 2회 + Lens 최대 2회 | 동일 상한, 검증 OCR은 보통 1회 후 Lens 생략 |
| Tavily 한국 검색 | 최대 2회 + 조건부 역검색 1회 | 동일 |
| Foundry | OCR 정제 0~1회 + 일본 판정 1회 + 한국 판정 1회 + 조건부 통용명 재판정 1회 | 동일, 무근거/거부 결과는 후속 판정 생략 |

정상 OCR 경로의 기존 Foundry 호출은 보통 3회, 통용명 재판정 포함 최대 4회다. 이는 TRD의 최종 판정 1회 목표와 기존 코드 간 불일치이며 이번 작업에서 승인 없이 호출 구조를 바꾸지 않는다. 약한 OCR 근거는 조기 성공으로 취급하지 않으므로 상한 내 Tavily/Lens 사용량은 늘 수 있고, 평균 비용 감소를 실측 없이 보장하지 않는다.

실제 OCR.space, SerpApi, Tavily, Azure Foundry, YES24, 국립중앙도서관 호출은 모두 0회다. mock 회귀 테스트만 실행했으며, 실제 정답률·p95 지연·과금은 측정하지 않았다.

## 실행 원칙

- 무료 Gemini Key로 반복 호출하지 않는다.
- 동일 이미지를 자동 재시도하지 않는다.
- 단계 timeout은 12초, 전체 timeout은 60초를 넘기지 않는다.
- 원본 이미지, 검색 원문, API Key는 로그와 결과 파일에 저장하지 않는다.
